# Library Tech 📖

- É um projeto que visa otimizar o cadastramento e manutenção de livros de maneira virtual. Indo contra o processo manual, muitas vezes, associado a esse processo.

## Status do projeto 🪛🔨

- Ainda em desenvolvimento. Porém, se encontra em uma versão já funcional.
